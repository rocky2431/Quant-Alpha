# 03 来源、实体、事件归因与有证据的语义提取

> **2026-09-17 当前讨论稿｜未批准实施。** [索引](README.md) · 上游：[02 对齐](02-CLEANING-ALIGNMENT.md) · 下游：[04 表示](04-OPERATORS-REPRESENTATIONS.md)

## 1. 目的与“归因”的第一层含义

回答谁在何时以何种身份提出了什么主张、它属于哪个事件、与此前信息有什么关系。这里是**信息来源和事件归属**，不是认定该信息造成 BTC 涨跌。模型/交易失败的诊断由 [09](09-RESEARCH-FEEDBACK.md) 负责。

输入为可用的原始文本、历史同事件版本、实体映射和来源信息；输出 `EventEvidence`，带原文证据、版本、提取配置、关系、未知与处理完成时刻。不能只输出没有来源的“利多分数”。

## 2. 语义对象与提取边界

| 字段组 | 提取内容 |
|---|---|
| 来源 | 原始链接/记录、作者或机构、直接发布/引用/转述、可信度依据 |
| 事件和实体 | `event_id`、事件类型、涉及主体、经济对象、影响范围；同名实体的置信度 |
| 主张 | 原文主张、提案/意向/决定/已生效、条件、期限、数值/单位、否定与不确定性 |
| 变化 | 相对当时已知旧版本的新增/撤回/修正，不相对未来文本比较 |
| 证据 | 支持每个关键字段的原文片段和位置；冲突来源分别保留 |
| 时间/版本 | 原文版本、发布与可用时间、提取器/模型/提示版本、提取完成时刻 |

“与市场预期相比意外多少”需要当时可得的预期数据和定义。没有预期源时，只能描述声明内容与历史变化，不能由 LLM 编造共识或真实 surprise 标签。训练预测标签可以使用其后实际结果，但它属于 06 的训练目标，不能混入当前事件解释和策略观察。

## 3. 具体处理过程

1. 按决策时可得资料识别直接来源、转述链和实体；实体不确定时保留候选，避免错误合并。
2. 建立事件组：同一声明的转载共享事件关联，原始记录仍保留。
3. 对每条主张抽取结构化字段与证据，检查数字、否定、条件和时态。
4. 区分首次披露、传播、独立确认、修正、矛盾。重复传播可能影响注意力，不能一律删除；独立确认不按相同文本去重。
5. 将提取错误/未知显式输出，对无法由证据支持的内容不填确定值。
6. 记录提取版本与耗时，再交 02/04 判断何时进入特征；保留可复查样本。

## 4. BTC 示例

FOMC 声明出现新的条件性措辞，系统记录该措辞、与上一已知声明的差异及证据；一家媒体随后转述，另一个来源给出不同解读。最小实例至少保留声明原文与变化，不把评论解读写成官方主张，也不直接贴“未来一小时上涨”的语义标签。

用户举的公开人物政策言论可以采用同样对象，但说话、正式行政文件、生效及司法变化属于不同事件阶段。Polymarket YES/NO 信息若将来加入，应先核对事件范围和结算条件，再作为有摩擦的市场观测；不能按关键词把它与 BTC 的某个未来事件等同。

## 5. 模型使用与历史污染

最小方案建议使用固定 LLM/提取规则生成带证据字段，先与简单结构化基线比较。它是推理组件，不是 SFT。若后续训练提取器，使用单独标注与时间分组，记录真实参数变化。

历史 LLM 可能已经见过事件及结果。固定版本、限制检索到当时材料和证据核对能减少部分问题，不能证明已清除预训练记忆；需要前向提取和前向评价补充证据。[历史文本与 LLM 前视研究](https://arxiv.org/abs/2309.17322)。

## 6. 失败观测与分阶段能力

主要可观测错误包括：实体误合并、把转述当原始事实、忽略否定/条件、未来资料混入、冲突被强行平均、提取延迟超过策略窗口。检查语义正确率和证据覆盖，还要看纠正后下游结果是否变化，不能只优化文本评分。

| 阶段 | 本环节实质内容 | 验证与推进条件 |
|---|---|---|
| 最小 MVP | 一类官方宏观事件的主张、变化、证据、版本和时间；固定提取器；与微观状态在下游连接 | 对代表性事件人工核查关键字段，保留未知/反例；输入不携带未来收益叙事 |
| 第二步：针对失败补强 | 若错误集中于否定、条件、实体或转述，补标注/规则；有需要时增加一个独立确认源或提取器 SFT | 独立事件组上的提取改进及对应下游增量；提交权重产物才称 SFT |
| 第三步：跨状态与运行验证 | 覆盖修正、冲突、不同发布形式、实时延迟；检验语义提取漂移与前向一致性 | 新事件上的证据支持率、延迟与失败处置达目标；不依赖历史记忆解释未来 |
| 完整能力：可复用研究产品 | 多来源事件/实体/主张关系，可追溯传播与修订，可供多任务查询 | 每个合并和推断可区分事实/假设，跨来源价值由实验验证；不以知识图规模验收 |

## 7. 依赖与待定

02 提供版本和时点；04 定义结构化字段如何变成可计算表示；05 决定传播、确认、冲突怎样组合；08/09分别评价预测贡献和诊断错误。待定为首类事件、提取字段、标注样本、基础模型版本、可接受错误类型与延迟。模型的流畅解释不是可信度或因果性的替代指标。
